# Digital Circuit Simulator (Java Swing)

> ⚠️ **[Warning]** This project is no longer actively maintained.

A simple digital circuit simulator built with Java Swing, designed to visually create and test basic logic circuits.

---

## ✨ Features

- Add and delete components such as:
  - AND, OR gates
  - Switches
  - Probes (output indicators)
- Connect components via auto-generated wires  
- Run basic logic simulation  

---

## ⚠️ Limitations

- Wires are auto-generated and **cannot be manually deleted**  
- Simulation may produce incorrect results when **input pins are connected directly to other input pins**  
- No ability to move or pan the workspace
